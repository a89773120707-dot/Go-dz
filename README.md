# Bin Manager

CLI-утилита для управления бинами (бинами данных) через **JsonBin API**. Позволяет создавать, получать, обновлять и удалять облачные JSON-хранилища прямо из терминала.

---

## 📋 Возможности

- **Создание** бина из JSON-файла
- **Получение** содержимого бина по ID
- **Обновление** бина из JSON-файла
- **Удаление** бина по ID
- **Список** всех сохранённых бинов (локальный кэш)

---

## 🚀 Быстрый старт

### Требования

- Go 1.25.5 или выше
- Аккаунт на [jsonbin.io](https://jsonbin.io)
- API-ключ от JsonBin

### Установка

```bash
cd 3-bin_manager

# Сборка
go build -o bin_manager.exe .
```

### Настройка

1. Создайте файл `.env` в корне проекта:
```env
KEY=ваш_api_ключ_от_jsonbin
```

2. **Где взять API-ключ:**
   - Зарегистрируйтесь на https://jsonbin.io
   - Войдите в [Dashboard](https://jsonbin.io/dashboard)
   - Скопируйте ключ из раздела "API Keys"

> ⚠️ **НИКОГДА не коммить `.env` в репозиторий!** Файл уже в `.gitignore`.

## 📖 Команды

### `--list` — Список всех бинов

Выводит список всех бинов, сохранённых локально.

```bash
go run . --list
```

**Пример вывода:**
```
Сохранённые бины:
1. my-bin              | ID: 69d74dd5856a68218913dbd5   | публичный | 2026-04-09 19:26
2. test                | ID: abc123def456...             | приватный | 2026-04-10 10:15
```

---

### `--create` — Создать бин

Создаёт новый бин в JsonBin из JSON-файла и сохраняет локально.

```bash
go run . --create --file=data.json --name=my-bin
```

| Флаг | Обязательный | Описание |
|------|-------------|----------|
| `--file` | ✅ | Путь к JSON-файлу |
| `--name` | ✅ | Имя бина (для локального списка) |

**Пример:**
```bash
go run . --create --file=accounts.json --name=user-accounts
```

**Результат:**
```
Бин 'user-accounts' создан. ID: 69d74dd5856a68218913dbd5
```

---

### `--get` — Получить бин

Получает и выводит содержимое бина по ID напрямую из JsonBin.

```bash
go run . --get --id=69d74dd5856a68218913dbd5
```

| Флаг | Обязательный | Описание |
|------|-------------|----------|
| `--id` | ✅ | ID бина в JsonBin |

**Пример вывода:**
```json
{
  "login": "user@example.com",
  "password": "secret123",
  "url": "https://example.com"
}
```

---

### `--update` — Обновить бин

Заменяет содержимое бина данными из JSON-файла.

```bash
go run . --update --id=69d74dd5856a68218913dbd5 --file=updated.json
```

| Флаг | Обязательный | Описание |
|------|-------------|----------|
| `--id` | ✅ | ID бина в JsonBin |
| `--file` | ✅ | Путь к JSON-файлу с новыми данными |

> ⚠️ JsonBin **не поддерживает частичное обновление**. `--update` заменяет **весь** JSON бина целиком.

**Результат:**
```
Бин 69d74dd5856a68218913dbd5 обновлен.
```

---

### `--delete` — Удалить бин

Удаляет бин из JsonBin и локального кэша.

```bash
go run . --delete --id=69d74dd5856a68218913dbd5
```

| Флаг | Обязательный | Описание |
|------|-------------|----------|
| `--id` | ✅ | ID бина в JsonBin |

**Результат:**
```
Бин 69d74dd5856a68218913dbd5 удалён
```

## 🏗️ Архитектура

### Пакеты

| Пакет | Отвечает за |
|-------|-------------|
| `api` | HTTP-запросы к JsonBin API |
| `bin` | Модели данных, бизнес-логика, интерфейс репозитория |
| `config` | Загрузка API-ключа из `.env` |
| `file` | Интерфейс файловой системы + реализация хранилища |
| `storage` | Legacy-код для бинарных файлов (не используется в CLI) |

### Dependency Inversion

Проект использует принцип **инверсии зависимостей** для избежания циклических импортов:

```
main.go
  ├── bin (объявляет интерфейс BinRepository)
  └── file (реализует BinRepository + FileSystem)
```

- `bin` пакет **не знает** про `file` — только про интерфейс `BinRepository`
- `file` пакет **знает** про `bin.Bin` и реализует `BinRepository`
- `main.go` — "сборочный слой": создаёт `FileBinRepository` и передаёт в `BinList`

### Хранение данных

| Где | Что хранится | Формат |
|-----|-------------|--------|
| **JsonBin** (облако) | Содержимое бинов (данные) | JSON |
| **newdata/** (локально) | Метаданные бинов (ID, имя, приватность, дата) | Отдельный `.json` файл на бин |

## 🔧 JsonBin API

**Базовый URL:** `https://api.jsonbin.io/v3/b`

| Операция | Метод | Заголовки |
|----------|-------|-----------|
| Create | `POST /v3/b` | `X-Master-Key`, `Content-Type: application/json` |
| Get | `GET /v3/b/{id}` | `X-Master-Key` |
| Update | `PUT /v3/b/{id}` | `X-Master-Key`, `Content-Type: application/json` |
| Delete | `DELETE /v3/b/{id}` | `X-Master-Key` |

### Формат ответа Create

```json
{
  "record": { ...отправленные данные... },
  "metadata": {
    "id": "69d74dd5856a68218913dbd5",
    "createdAt": "2026-04-09T19:26:00.000Z"
  }
}
```

### Формат ответа Get

```json
{
  "record": { ...содержимое бина... },
  "metadata": {
    "id": "69d74dd5856a68218913dbd5",
    "modifiedAt": "2026-04-09T19:26:00.000Z"
  }
}
```

## 🧪 Тестирование

### Полный цикл

```bash
# 1. Help
go run .

# 2. Пустой список
go run . --list

# 3. Создать тестовый JSON-файл
echo {"key": "value"} > test.json

# 4. Создать бин
go run . --create --file=test.json --name=test-bin

# 5. Проверить что появился в списке
go run . --list

# 6. Получить содержимое
go run . --get --id=<ID_из_создания>

# 7. Обновить
go run . --update --id=<ID> --file=test.json

# 8. Удалить
go run . --delete --id=<ID>

# 9. Проверить что пропал
go run . --list
```

```bash
go build -o bin_manager.exe .

```

## ⚠️ Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Ошибка: неверный API ключ (401)` | Неверный или просроченный ключ в `.env` | Проверить ключ на jsonbin.io |
| `Хранилище не найдено (404)` | Bin с таким ID не существует | Проверить ID, создать новый бин |
| `Доступ запрещён (403)` | Ключ заблокирован | Обратиться в поддержку JsonBin |
| `Слишком много запросов (429)` | Превышен лимит | Подождать |
| `Ошибка чтения файла` | Файл не существует или нет доступа | Проверить путь и права |
| `Ошибка парсинга json` | Файл не валидный JSON | Проверить синтаксис файла |
